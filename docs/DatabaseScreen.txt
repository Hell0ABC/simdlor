DatabaseScreen - экран с таблицами базы данных. После выбора и подключения к базе данных, приложение меняется на этот экран, где можно открывать, редактировать, удалять и добавлять новые таблицы

Код:
_refresh_tables и _build_table_item - функции для заполнения RecycleView таблицами
_open_table - фукнция открытия таблицы и перехода на TableScreen
_anim_to - анимация для открытия FAB-меню
toggle_fab_menu - открытие меню
close_fab_menu - закрытие меню и переход
action_home - переход на HomeScreen
action_save - сохраняет изменения (почти в каждой функции изменения данных в БД есть сохранения, однако кнопку можно использовать для дальнейшего функционала или на случай если сейвы из функций не сработают)
handle_fab_action - добавление действий для меню
